File List

Displays uploaded files with visual states for uploading, success, error, and neutral. Supports preview (TXT/PDF), download mode, expandable error messages, and optional error report download.

All states with preview and error report

Downloadable FileList with callback

# API Reference

Property Type Default Description
Component Inputs
files UploadedFiles[] [] Required. Array of file objects to display in the list. Each file object contains file information, upload status, progress, and optional error messages. The component automatically formats file sizes and displays different UI states based on the file status. See the UploadedFiles Type section below for details.
isDownloadable boolean false When true, displays a download button for each file instead of a delete button. When false, shows a delete button for successfully uploaded files. If onDownload has listeners, it emits the file; otherwise, triggers a default browser download.
isPreviewable boolean false When true, shows an eye icon next to the delete button for successfully uploaded files and opens a popup to preview the file (TXT and PDF only). When false, preview is disabled.
showErrorButtonUpload boolean false When true, displays a Télécharger le rapport des erreurs button on files with status === 'error' and a non-empty errors array. Handle the click via onDownloadErrors.
maxHeight number | undefined undefined Optional maximum height in pixels for the file list container. When set, the list scrolls vertically once content exceeds this height.
isMultiple boolean false When true, indicates that multiple files can be displayed. Currently used for internal logic and future enhancements. The component supports displaying multiple files regardless of this setting.
className string '' Optional additional CSS classes to apply to the file list container. Useful for custom styling or layout adjustments.
Component Outputs (Events)
onDelete EventEmitter<string> - Emitted when a file's delete button is clicked. Provides the file ID (string) as the event value. Use to handle file deletion and remove the file from your data source. Shown for files with status === 'success' when isDownloadable is false, and for files with status === 'error'.
onDownloadErrors EventEmitter<string> - Emitted when the error report download button is clicked (only when showErrorButtonUpload is true and the file has errors). Provides the file ID (string). Use to generate or download a validation error report.
onDownload EventEmitter<File> - Emitted when a file's download button is clicked (when isDownloadable is true). Provides the File object as the event value. If no listeners are registered, the component automatically triggers a browser download. Use to handle custom download logic (e.g., server-side downloads, custom file handling).
onPreview EventEmitter<File & { id: string }> - Emitted when the eye (preview) button is clicked on a successfully uploaded file (only when isPreviewable is true and isDownloadable is false). The component also opens a built-in popup that previews TXT and PDF files. Unsupported types show a fallback message with a download action.

# UploadedFiles Type

The UploadedFiles type defines the structure for file objects passed to the files input property.

Property Type Default Description
file File & { id: string } - Required. The File object with an additional id property. The File object contains standard file properties (name, size, type, etc.). The id property must be a unique string identifier used for tracking, deletion, and error management. The component uses this ID to identify files when emitting events.
status 'uploading' | 'success' | 'error' undefined Optional upload status that determines the visual state and available actions. Available options: 'uploading' (shows a loading spinner), 'success' (shows success styling with optional preview eye icon and delete/download button), 'error' (shows error styling with delete button, expandable error messages, and optional error report download). When not provided, displays a neutral state with file information.
progress number undefined Optional upload progress percentage (0-100). Typically updated by the parent while status === 'uploading'. The UI currently shows a loading spinner during upload; this value is available for parent-side logic or future UI enhancements.
errors null | string[] undefined Optional array of error messages. Only used when status === 'error'. When provided, displays an expandable error section with a list of error messages. Users can click to expand/collapse the error list. Each error is displayed as a bulleted list item. Use to provide detailed validation or upload error information to users.
