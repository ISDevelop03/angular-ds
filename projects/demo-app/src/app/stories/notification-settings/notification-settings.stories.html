NotificationSettings

# API Reference

Property Type Default Description
Component Inputs
title string '' Heading displayed next to the settings icon at the top of the card.
description string '' Supporting text shown under the title. Use it to explain the scope of the setting, for example that one toggle applies to every listed operation.
notificationsEnabled boolean false Whether notifications are currently enabled. Controls the toggle state and the status label: 'Activées' when true, 'Désactivées' when false. Updated internally when the user flips the toggle.
notifications string[] [] Labels of the operations the user is notified about. Each item is rendered as a bullet under 'Vous êtes notifié pour :'. An empty array renders the section with no bullets.
className string '' Optional additional CSS classes applied to the root container. Useful for custom spacing or layout adjustments.
Component Outputs (Events)
notificationsChange EventEmitter<boolean> - Emitted when the user toggles notifications. The payload is the new enabled state: true when notifications are turned on, false when they are turned off.
