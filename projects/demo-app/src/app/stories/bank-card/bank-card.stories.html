Bank Card

Selectable bank card option used in the commande de cartes configuration step. Shows a large card visual, title, description and a radio indicator.

With images (selection grid)

Click a card to select it. The parent owns selected and listens to onSelect.

CSS fallback (no image)

When imageSrc is omitted, a gradient fallback by variant is shown.

Single card

Isolated selected state.

# API Reference

Property Type Default Description
Component Inputs
variant 'business' | 'deposit' | 'escale' 'business' Card product variant. Emitted by onSelect and drives the CSS fallback when no image is provided.
label string '' Title shown under the visual (e.g. 'VISA BUSINESS').
description string Default Visa Business marketing copy Supporting text under the title.
selected boolean false When true, applies the red active border and fills the radio indicator.
imageSrc string | null null Optional product image (16:10). When omitted, a CSS gradient fallback for variant is shown.
alt string | null null Image / fallback accessible label. Defaults to a label derived from variant.
className string '' Optional additional CSS classes on the root button.
Component Outputs
onSelect EventEmitter<CardVariant> — Emitted when the card is clicked. Payload is the variant input.
