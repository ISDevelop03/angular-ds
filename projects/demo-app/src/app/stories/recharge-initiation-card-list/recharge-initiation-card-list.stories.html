Recharge Initiation Card List

Scrollable list of card rows for the recharge initiation tab. Each row shows card visual, holder, masked number, expiry, balance, and a recharge action.

List

Pass cards and listen to onOpen when the eye button is clicked.

Single row

Use ds-recharge-card-row directly when you only need one row.

# API Reference — ds-recharge-initiation-card-list

Property Type Default Description
Component Inputs
cards RechargeCardRowData[] [] Required. Cards to render as rows.
productName string 'Escale PRO' Product label shown in each row.
actionLabel string 'Recharger' Accessible label and tooltip for the action button.
className string '' Optional additional CSS classes on the root wrapper.
Component Outputs
onOpen EventEmitter<RechargeCardRowData> — Emitted when the recharge action is clicked on a row.

# RechargeCardRowData Interface

Shared by ds-recharge-initiation-card-list and ds-recharge-card-row.

Property Type Default Description
id string — Required. Unique row identifier.
holder string — Required. Cardholder name.
numTail string — Required. Masked card number (e.g. 43•••• 3456).
expiry string — Required. Expiration date.
solde number — Required. Balance in MAD (can be negative).
variant 'deposit' | 'business' | 'escale' 'escale' Card visual variant forwarded to ds-card-visual.
productName string undefined Optional per-row product label override.
