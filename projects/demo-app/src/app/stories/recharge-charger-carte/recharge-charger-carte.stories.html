Recharge Charger Carte

Expandable card summary for the recharge flow: visual, holder info, amount tiles, and address details behind Voir plus / Voir moins.

Expanded

Click the footer to collapse. Tiles and details come from card.tiles and card.details.

Collapsed

Header + toggle only when expanded is false.

# API Reference

Property Type Default Description
Component Inputs
card RechargeChargerCarteData — Required. Card data passed to the component. See the RechargeChargerCarteData Interface section below.
expanded boolean false When true, shows tiles and detail rows below the toggle.
expandLabel string 'Voir plus' Label shown when collapsed.
collapseLabel string 'Voir moins' Label shown when expanded.
className string '' Optional additional CSS classes on the root wrapper.
Component Outputs
onToggle EventEmitter<RechargeChargerCarteData> — Emitted when the Voir plus / Voir moins button is clicked.

# RechargeChargerCarteData Interface

The RechargeChargerCarteData interface defines the structure for the card input property and the payload emitted by onToggle.

Property Type Default Description
name string — Required. Card title shown in the header (e.g. VISA - Escale PRO).
holder string — Required. Cardholder name.
numTail string — Required. Masked card number tail (e.g. 43•••• 3456).
expiry string — Required. Expiration date displayed after Date d'expiration.
variant 'deposit' | 'business' | 'escale' — Required. Card visual variant forwarded to ds-card-visual.
imageSrc string undefined Optional product image override for the card thumbnail.
tiles RechargeChargerCarteTile[] undefined Optional summary tiles shown in the expanded panel (e.g. Solde chargé, Plafond retrait, Plafond achat). See RechargeChargerCarteTile Interface below.
details RechargeChargerCarteDetail[] undefined Optional label/value rows shown below the tiles (e.g. Nom, Pays, Ville, Adresse). See RechargeChargerCarteDetail Interface below.

# RechargeChargerCarteTile Interface

The RechargeChargerCarteTile interface defines each summary tile in the expanded panel grid.

Property Type Default Description
label string — Required. Tile label (e.g. Solde chargé).
value string — Required. Formatted amount or value (e.g. 4 350 MAD).
tint 'green' undefined When set to 'green', renders the tile with a success background and green label/value text (used for Solde chargé).

# RechargeChargerCarteDetail Interface

The RechargeChargerCarteDetail interface defines each label/value row in the expanded details section.

Property Type Default Description
label string — Required. Row label (e.g. Nom, Pays).
value string — Required. Row value, right-aligned in bold.
