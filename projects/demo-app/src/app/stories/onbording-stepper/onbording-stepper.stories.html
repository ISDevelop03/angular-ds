# API Reference

Property Type Default Description
Component Inputs
className string '' Optional CSS classes on the stepper container.
variant 'default' | 'open' 'default' default shows one active step, marks earlier steps completed, and mutes the rest. open shows every step's content and keeps every marker numbered.
activeIndex number 0 Index of the step that shows its content. Steps before it are completed. Steps after it stay muted. Bind it to move between steps, for example [activeIndex]="activeIndex".
Component Outputs
activeIndexChange EventEmitter<number> - Emits the new index when next(), prev(), or goTo() runs. Use (activeIndexChange) or [(activeIndex)].
Methods
next() void - Moves to the next step when one exists.
prev() void - Moves to the previous step when one exists.
goTo(index) void - Moves to the step at index.
Content Projection
ds-onbording-step ng-content - Required. Project one ds-onbording-step per step. Each step can host any HTML or component. In the default variant that content is shown only while the step is active. In the open variant every step shows its content.

# OnbordingStep

ds-onbording-step is one row projected into ds-onbording-stepper. The stepper draws the marker, the line, and decides which step content is visible.

Property Type Default Description
title string '' Label shown beside the marker. It stays visible for every step.
Content Projection
ng-content - - Any content projected inside the step (HTML, text, or components). It is the body of that step. The default variant shows it only while the step is active. The open variant shows it for every step.
