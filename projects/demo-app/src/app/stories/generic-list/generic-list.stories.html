# API Reference

Property Type Default Description
Component Inputs
sections GenericListSection[] [] Array of titled sections. Each section groups a set of list items under a title. See the GenericListSection Interface section below.
variant 'white' | 'gray' 'white' Visual variant. white uses bg-level-3 with neutral-900 labels. gray uses bg-neutral-25 with neutral-500 labels.
className string '' Optional additional CSS classes applied to the root container.

# GenericListSection Interface

Each object in the sections array matches GenericListSection: a title, optional display mode, and a list of items.

Property Type Default Description
title string - Required. Section title displayed above its items.
display 'inline' | 'stacked' 'inline' Layout for items in the section. inline places label and value on the same line. stacked places them on separate lines with a 10px gap.
items GenericListItem[] - Required. List items belonging to this section. See the GenericListItem sections below.

# GenericListItem — text

Simple label / string value row.

Property Type Default Description
type 'text' - Required. Discriminator for text items.
label string - Required. Label text for the row.
value string - Required. Text value displayed next to (or below) the label.

# GenericListItem — list-badges

Label with a row of ds-badge chips.

Property Type Default Description
type 'list-badges' - Required. Discriminator for badge list items.
label string - Required. Label text for the row.
value string[] - Required. Badge labels rendered as small badges.

# GenericListItem — account

Label with account name and account number.

Property Type Default Description
type 'account' - Required. Discriminator for account items.
label string - Required. Label text for the row.
value {{ '{' }} accountName: string; accountNumber: string {{ '}' }} - Required. Account details. accountName is bold; accountNumber is shown below in neutral-500.
