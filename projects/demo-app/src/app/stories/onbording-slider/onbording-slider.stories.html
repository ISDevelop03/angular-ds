# API Reference

Property Type Default Description
Component Inputs
className string '' Optional additional CSS classes to apply to the slider container. Useful for custom styling or layout adjustments (e.g., setting max width and padding: w-full max-w-[400px] bg-level-2 p-4).
showDots boolean true When true, displays pagination dots and previous/next arrows when more than one ds-onbording-slide is projected. When false, the navigation row is hidden. Dots jump to a slide; arrows move one slide at a time and are disabled on the first and last slides.
Content Projection
ds-onbording-slide ng-content - Required. Project one or more ds-onbording-slide elements. The slider shows one slide at a time. Each slide can host any HTML or component. See the OnbordingSlide section below for details.

# OnbordingSlide

ds-onbording-slide is one screen projected into ds-onbording-slider. The slider handles layout, the active slide, and the dots.

Property Type Default Description
active boolean false Selects this slide when the slider loads. Set active or [active]="true" on the slide that should be visible first. The slider then keeps this in sync as the user moves between slides. When no slide is marked active, the first slide is shown.
Content Projection
ng-content - - Any content projected inside the slide (HTML, text, or components). That content is the body of the slide.
