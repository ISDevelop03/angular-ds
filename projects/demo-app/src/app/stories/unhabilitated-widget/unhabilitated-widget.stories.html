UnhabilitatedWidget

# API Reference

Property Type Default Description
Component Inputs
backgroundImage string '' URL of the image that fills the widget behind the overlay. It is rendered full size and covered by a dark scrim so the modal stays readable.
modalImage string '' URL of the illustration shown inside the centered modal, above the title. Displayed at a fixed width of 176px.
title string '' Heading displayed inside the modal, under the illustration.
description string '' Supporting text shown under the title. Use it to explain why access is unavailable and where the user can continue.
className string '' Optional additional CSS classes applied to the root container. Useful for custom spacing or layout adjustments.
