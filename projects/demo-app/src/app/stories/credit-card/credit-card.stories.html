Credit Card

Expandable credit card. Tab panels use the same ITab[] shape as ds-tabs (title + panel as string or TemplateRef).

Expanded

Click the header to collapse. Tabs render panel content from items.

Collapsed

Header-only state when expanded is false.

# API Reference

Property Type Default Description
Component Inputs
card CardItem — Required. Card data shown in the row header (name, holder, numTail, expiry, plafonds, solde, variant).
expanded boolean false When true, shows the tabs panel below the header.
items ITab[] [] Same as ds-tabs. Each item has title and panel (string or TemplateRef). Panels are managed by ds-tabs.
selectedIndex number 0 Initially selected tab index, forwarded to ds-tabs.
className string '' Optional additional CSS classes on the root wrapper.
Component Outputs
onToggle EventEmitter<CardItem> — Emitted when the row header is clicked.
onTabChange EventEmitter<{{ '{' }} index: number; tab: ITab {{ '}' }}> — Emitted when a tab is selected inside the expanded panel.
