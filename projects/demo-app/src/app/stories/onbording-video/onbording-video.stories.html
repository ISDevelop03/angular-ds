OnbordingVideo

Pass a thumbnail with imageSrc and a video with videoUrl. Clicking the YouTube icon opens a 16:9 popup and plays the video. YouTube and Vimeo links open as embeds. A file URL plays in a video player.

YouTube

# API Reference

Property Type Default Description
Component Inputs
videoUrl string '' Video to play when the thumbnail is clicked. A YouTube (watch, youtu.be, embed, shorts) or Vimeo link opens in an embed. Any other URL plays in a native video element.
imageSrc string '' Thumbnail image shown behind the YouTube play icon.
imageAlt string 'Play video' Accessible name for the thumbnail button and alt text for the image.
className string '' Optional classes added to the thumbnail button, for width or extra layout.
