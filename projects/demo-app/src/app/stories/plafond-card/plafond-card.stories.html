Plafond Card

Editable (national style)

Read-only with note (international style)

# API Reference

Property Type Default Description
Component Inputs
title string '' Card title displayed in uppercase (e.g. 'Retrait GAB Saham Bank').
editable boolean false When true, shows the red edit icon that emits onEdit.
color 'green' | 'orange' | 'red' | 'olive' 'green' Visual color of the filled arc. When percent is omitted, also drives a default fill ratio.
percent number | null null Fill ratio from 0 to 1. When omitted, a ratio derived from color is used.
consumed string '' Main value displayed under the label inside the gauge.
max string '' Right-side footer label for the maximum value.
contractuel string '' Value shown next to PLAFOND CONTRACTUEL.
commercial string '' Value shown next to PLAFOND COMMERCIAL.
note string '' Optional helper text shown below the gray box.
className string '' Optional additional CSS classes applied to the root wrapper.
Component Outputs
onEdit EventEmitter<void> — Emitted when the edit icon is clicked.
